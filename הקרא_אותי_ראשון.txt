🐛 בעיות נפוצות
───────────────────────────────────────────────────────────

❌ "Python is not recognized"
   → התקן Python עם "Add to PATH" + אתחל מחשב

❌ Windows Defender חוסם
   → "More info" → "Run anyway" (זה בטוח!)

❌ לא מתחבר לשרת
   → ודא ש-python app.py רץ או השתמש ב-run_cubase_assistant.bat

❌ חבילות חסרות
   → pip install -r requirements.txt

💡 למה זה עובד ככה?
───────────────────────────────────────────────────────────

PyInstaller יוצר executables למערכת ההפעלה שעליה הוא רץ:

🐧 Linux → ELF executable   (לא עובד על Windows)
🪟 Windows → .exe file       (עובד על Windows)

לכן, כדי לקבל Windows .exe, צריך לבנות על Windows!

הסקריפטים שיצרתי (install_and_build.bat) עושים את זה
אוטומטית בשבילך.
